# Política de segurança

## Reportar uma vulnerabilidade

Envie um relatório privado pelo recurso **Report a vulnerability** na aba Security deste repositório. Se o recurso não estiver disponível, entre em contato por `rodolfofrancoxico@gmail.com`. Inclua passos para reproduzir o problema e o impacto observado; não publique detalhes antes de uma correção estar disponível.

## Limites do servidor

O servidor estático deve servir apenas os caminhos explicitamente listados em `PUBLICOS`, em `server.js`. Arquivos do repositório, configurações, histórico Git e testes não devem ser publicados.
